# Project Journal – Hitesh

**Project: Distributed Search Engine**

## Work Completed So Far

### 1. Distributed Search Engine Architecture

Studied the architecture and working of a distributed search engine, focusing on:

* Microservices and service-oriented architecture
* Horizontal scaling and workload distribution
* Fault tolerance and load balancing
* Data partitioning and replication
* Communication between distributed services

Identified the major components: **Document Ingestion, Indexing, Search Shards, Query Coordinator, Ranking, and Caching Services.**

### 2. Search Engine Internals

Studied the fundamentals of search engines, including:

* Text tokenization and preprocessing
* Inverted indexing
* Stop-word removal
* TF-IDF and relevance-based ranking
* Distributed query processing

### 3. Spring Boot Backend

Started learning **Spring Boot** for developing the backend microservices and REST APIs of the system.

### 4. System Workflow & Requirements

Designed the initial system workflow and identified the main functional requirements, covering document ingestion, indexing, and query processing.

### 5. Activity Diagram Implementation

Implemented the **Activity Diagram** to represent the step-by-step flow of the system, including document submission, indexing, query processing, searching across shards, ranking, and displaying results.

### 6. ER Diagram

Created the initial **ER diagram** to represent the data model, entities, attributes, and relationships within the system.
